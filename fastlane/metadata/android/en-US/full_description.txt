An AI that doesn't just talk. It acts.

AIOPE is a fully autonomous AI agent that lives on your Android device: 48 tools, realtime voice with full tool access, a complete Linux terminal in your pocket, browser automation, an on-device RAG knowledge base, remote server management over SSH, live location and data feeds, and the ability to build native interactive UI on the fly.

The agent loop runs entirely on-device: reason, call a tool, read the result, decide, repeat — up to 140 rounds per turn. AIOPE can research a topic, write code, save it, run it in the terminal, fix the errors, and report back, all in a single turn. It spawns background agents, runs multi-agent DAG pipelines, schedules recurring tasks, and can execute every one of its tools by voice.

FOUR MODES
• Chat — conversational AI with full tool access
• Voice — realtime bidirectional voice with full tool access
• Plan — read-only analysis; explore context and produce a structured plan
• Build — autonomous execution; chain tools without confirmation until done

HIGHLIGHTS
• 48 tools: shell, Alpine Linux (proot), file I/O, SMS, contacts, calendar, alarms, web/image search, URL fetch, live data feeds, browser automation, GPS, image generation, vision, persistent memory, RAG, SSH remote servers
• Realtime voice with acoustic echo cancellation and live transcription
• Headless voice: start live voice from a floating mic or the assist gesture without opening the app; screen context is captured for prompt enrichment
• Dynamic native Compose UI generated by the AI in chat (30+ component types)
• Multi-agent system: spawn agents, monitor, schedule timers, orchestrate DAG pipelines
• On-device RAG over a local SQLite vector store; only embedding requests leave the device
• Provider-agnostic: works with any OpenAI-compatible API — BYOK, always

Ships pre-configured for the AIOPE Gateway and works out of the box, or connect your own keys and endpoints.

Requirements: Android 8.0+ (API 26), ARM64 device for the optional Linux terminal.
